# Harness logos

- `deepagents.svg`: unchanged 100 × 100 symbol extracted from the official Deep Agents OSS lockup in the [LangChain brand assets](https://www.langchain.com/brand-assets) package. Original colors and geometry are retained.
- `agentcore.svg`: adapted from the Amazon Bedrock AgentCore service icon in the supplied AWS Architecture Icons package dated July 31, 2026. The original vector glyph geometry and green `#01A88D` background color are retained. A black `#000000` glyph and circular background are local adaptations for contrast at small badge sizes.
- `claude.svg`: [Simple Icons Claude mark](https://github.com/simple-icons/simple-icons/blob/c71c69e3a27e4436936b831c72643e6513b9f49b/icons/claude.svg), distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/c71c69e3a27e4436936b831c72643e6513b9f49b/LICENSE.md), using the catalog's published brand color.

Brand marks belong to their respective owners. These local assets identify the selected execution harness and require no third-party requests at runtime.

## Protocol and framework marks

- `a2a.svg`: official SVG (trailing whitespace normalized; geometry and colors unchanged) from [A2A](https://raw.githubusercontent.com/a2aproject/A2A/4d7cda4b1754ed410e41bf3be7ad9ebc62afe3d3/docs/assets/a2a_logo/icon/color/SVG/a2a_icon_color.svg).
- `acp-light.svg`: unmodified official SVG from [agent-client-protocol](https://raw.githubusercontent.com/agentclientprotocol/agent-client-protocol/9ba75e72343d49e3c776519057b9520ed340a86b/docs/logo/light.svg).
- `acp-dark.svg`: unmodified official SVG from [agent-client-protocol](https://raw.githubusercontent.com/agentclientprotocol/agent-client-protocol/9ba75e72343d49e3c776519057b9520ed340a86b/docs/logo/dark.svg).
- `adk.svg`: unmodified official SVG from [adk-python](https://raw.githubusercontent.com/google/adk-python/56b25c61953b382ac161f9fef3470d5fec52598e/src/google/adk/cli/browser/assets/ADK-512-color.svg).

ACP uses the provided black/light and white/dark variants; see the [ACP brand guide](https://agentclientprotocol.com/brand). Claude Code and Claude Agent SDK share the Claude mark and retain distinct text labels. Framework selection is operator-supplied display metadata, not a runtime or protocol change.
