# Subscription Settings

- The inbox provides a subscriptions view. Settings supports app-owned event types, channel choices, pause/resume and quiet hours.
- External adapters that are not installed/configured remain unavailable.
- Followed resources remain managed by their owning app. A personal test endpoint is rate limited and uses the current account only.

Delivery gives a verified enabled account the same baseline `user` role as
sign-in. Administrator and custom app roles still require current identity-provider
role mappings. A cached administrator flag does not grant delivery access.
