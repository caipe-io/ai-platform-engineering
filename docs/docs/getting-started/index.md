# Getting Started

CAIPE is an open-source platform for using and operating AI agents with the
tools, knowledge, and workflows your team already uses.

You can:

- Build a governed agent with [Agent Builder](../features/agent-builder.md).
- Connect approved tools through [MCP servers](../agents/README.md).
- Ground answers in [Knowledge Bases](../knowledge_bases/index.md).
- Coordinate multi-step work with [Workflows](../features/workflows.md).
- Use CAIPE from the web UI, Slack, Webex, or the CLI.

This section helps you install CAIPE, sign in, and try a first request. For a
feature-by-feature map, see the [Features overview](../features/index.md).
For scenario-based examples, see the [Platform Engineer use cases](../usecases/platform-engineer.md).

---

## 💡 Example Prompts

Once you have an agent and its integrations configured, try requests such as:

- “Summarize the open deployment issues in repository `example-service`.”
- “Show the current on-call schedule for team `example-team`.”
- “Search the release guidance and list the required approval steps.”
- “Review this incident and suggest the next three actions.”
- “Create a ticket from this conversation for the platform team.”
