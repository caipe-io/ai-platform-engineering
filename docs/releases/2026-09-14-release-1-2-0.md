## Upgrade Guide: 1.1.0 → 1.2.0

### Overview

This is a drop-in upgrade. The only change currently present after the 1.1.0 tag is a
documentation-version index update; there are no application, runtime, persistence, or
Helm values changes to apply.

### Helm Values Changes

No Helm values changes between 1.1.0 and 1.2.0. Drop-in upgrade.

### Upgrade Runbook

#### 1. Back up deployment configuration

Save the current Helm values and take the normal persistence backup required by your
operational policy.

#### 2. Update the chart

```bash
helm upgrade ai-platform-engineering \
  oci://ghcr.io/caipe-io/charts/ai-platform-engineering \
  --version 1.2.0 \
  -f your-values.yaml
```

#### 3. Verify

```bash
kubectl get pods -n <namespace>
kubectl get events -n <namespace> --sort-by=.lastTimestamp
```

Confirm that the workloads remain healthy and that the documentation site reports the
expected deployed version.
