# Code of Conduct

CAIPE adopts and abides by the [CNCF Community Code of Conduct][cncf-coc].

## Reporting

Report potential violations privately to the CNCF Code of Conduct Committee at
[conduct@cncf.io](mailto:conduct@cncf.io).

- Follow the [CNCF Incident Resolution Procedures][incident-procedures]
  for reporting options, including anonymous reports.
- The [CNCF Jurisdiction Policy][jurisdiction]
  explains which response team handles an incident.
- Do not report conduct incidents in public GitHub issues.

[incident-procedures]: https://github.com/cncf/foundation/blob/main/code-of-conduct/coc-incident-resolution-procedures.md
[jurisdiction]: https://github.com/cncf/foundation/blob/main/code-of-conduct/coc-committee-jurisdiction-policy.md
